# 🧮 BMI Calculator

A simple and responsive **BMI (Body Mass Index) Calculator** built using HTML, CSS, and JavaScript.

This project allows users to enter their height and weight and instantly calculate their BMI along with the corresponding BMI category.

---

## 📌 Project Description

The BMI Calculator is a beginner-friendly web application designed to practice:

- HTML form handling
- CSS styling and responsive design
- JavaScript calculations
- Input validation
- Conditional statements
- DOM manipulation

Users can enter their height in centimeters and weight in kilograms to calculate their BMI.

---

## 🎯 Objective

The main objective of this project is to understand how to:

- Create and handle HTML forms
- Read user input using JavaScript
- Perform mathematical calculations
- Validate user input
- Display dynamic results
- Use `if / else if / else` conditions
- Update webpage content using the DOM

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – BMI calculation, validation, and DOM manipulation

---

## ✨ Features

- 📏 Height input in centimeters
- ⚖️ Weight input in kilograms
- 🧮 Automatic BMI calculation
- 📊 BMI category display
- ✅ Input validation
- ❌ Rejects empty values
- ❌ Rejects zero and negative values
- ❌ Rejects invalid values
- 🔢 BMI rounded to two decimal places
- 📱 Responsive design
- 🎨 Clean and modern user interface

---

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |

> Note: BMI is a general screening measure and does not by itself provide a medical diagnosis.
